# Finance MVP — Multi-Currency Financial Tracker

## Core Concept

A Flutter multi-currency financial tracking app focused on **currency de/revaluation management**. The user holds money in **VES** (Venezuelan Bolivar — national currency) and other currencies. The app tracks a **base/reference currency (default USD, configurable)** and shows:

1. **Unrealized FX gains/losses** — how much value holdings gained/lost as exchange rates moved
2. **Purchasing power erosion** — how much the national currency has weakened vs the reference currency over time

### Key Concepts

| Term | Meaning |
|------|---------|
| **Base Currency** | The user's personal reference for net worth (default USD, configurable in settings) |
| **National Currency** | VES — the local currency where the user operates |
| **Account Currency** | Each account can have its own currency |
| **Unrealized FX Gain/Loss** | `(currentRate - acquisitionRate) × amount` — value change due to rate movement |
| **Purchasing Power Erosion** | `(historicalRate / currentRate - 1) × 100` — how much the national currency weakened |
| **Acquisition Rate** | Exchange rate stored at transaction creation time (auto-captured or manual override) |

## API Integration — Frankfurter

- **Base URL**: `https://api.frankfurter.dev/v2`
- **No API key required**
- Supports 201 currencies, historical data from 1948
- VES may not be available — app falls back to manual entry with a warning

### Endpoints Used

| Endpoint | Purpose |
|----------|---------|
| `GET /v2/rates?base=USD&quotes=VES` | Latest rate |
| `GET /v2/rates?date=2026-01-15&base=USD` | Historical rate for specific date |
| `GET /v2/rates?from=2026-01-01&quotes=USD,VES` | Time series |
| `GET /v2/currencies` | List available currencies |

### `ExchangeRateApiService`

```dart
class ExchangeRateApiService {
  final http.Client _client;
  static const _baseUrl = 'https://api.frankfurter.dev/v2';

}
```

## Key Decisions

1. **Auto-capture exchange rate at transaction time** with manual override option
2. **Frankfurter API** as primary source, manual entry as fallback (especially for VES)
3. **USD as default base currency**, but configurable per user
4. **Drift DAOs** for cleaner data access separation
5. **ChangeNotifier** (not BLoC/Riverpod) to stay consistent with existing Provider usage
6. **Core MVP scope only** — no budgets, goals, recurrence, or export features yet
